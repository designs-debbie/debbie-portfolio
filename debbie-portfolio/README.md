# Debbie Portfolio

A responsive portfolio website for Debbie, built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — typing effect, mobile navigation, and contact form handling
- `images/` — profile and portfolio reference images

## Run locally

Open `index.html` in a browser. For the best local development experience, use VS Code with the Live Server extension.

## Formspree contact form

The contact form currently posts to `https://formspree.io/f/mrpebpej`.

Before relying on it:
1. Sign in to the Formspree account that owns this form ID.
2. Confirm the form is active and the recipient email is correct.
3. Complete any email verification Formspree requests.
4. Submit a test message from the published website and confirm it arrives.

If this form ID does not belong to your account, replace the `action` URL in `index.html` with your own Formspree endpoint.

## Publish with GitHub Pages

1. Create a public GitHub repository named `debbie-portfolio`.
2. Upload the contents of this folder (upload the files inside the folder, not just the ZIP).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to deploy. Your URL will usually look like:
   `https://YOUR-GITHUB-USERNAME.github.io/debbie-portfolio/`

The exact URL depends on your GitHub username and repository settings.
